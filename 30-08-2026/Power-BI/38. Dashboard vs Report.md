# Difference Between Dashboard and Report in Power BI

## Question
What is the difference between a **Power BI Report** and a **Power BI Dashboard**?

---

## 1. Comparison Matrix

| Feature | Power BI Report | Power BI Dashboard |
| :--- | :--- | :--- |
| **Creation Environment** | Power BI Desktop & Service. | **Power BI Service only** (Cloud). |
| **Pages** | Multi-page interactive canvas. | **Single page** high-level overview. |
| **Data Sources** | Single dataset per report. | **Pins visuals from multiple reports/datasets**. |
| **Interactivity** | Full slicing, filtering, drill-down. | Tiles link back to parent reports; limited slicing. |
| **Alerts & Q&A** | Q&A visual; no email alerts. | **Data Alerts (emails on metric thresholds)** & Natural Language Q&A. |
