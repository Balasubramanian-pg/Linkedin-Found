# Understanding Excel Pivot Tables

## Question
What is a Pivot Table in Excel, what are its components, and how do you use it for rapid exploratory data analysis?

---

## 1. What is a Pivot Table?

A **Pivot Table** is an interactive summary tool in Excel that allows you to calculate, summarize, group, slice, and cross-tabulate large tabular datasets without writing complex formulas.

---

## 2. The 4 Quadrants of a Pivot Table

```
+-----------------------------------+-----------------------------------+
|            FILTERS                |             COLUMNS               |
| (Page-level global slice filters) | (Categorical horizontal headers)  |
+-----------------------------------+-----------------------------------+
|             ROWS                  |             VALUES                |
| (Categorical vertical breakdown)  | (Numeric metrics: SUM, AVG, COUNT)|
+-----------------------------------+-----------------------------------+
```

---

## 3. Key Advanced Features
1. **Calculated Fields:** Add custom formulas within the pivot table (e.g., `Profit Margin = Profit / Revenue`).
2. **Show Values As:** Display metrics as `% of Grand Total`, `% of Column Total`, or `Running Total in`.
3. **Slicers & Timelines:** Visual interactive filter buttons that dynamically link across multiple pivot tables for dashboards.
