# RCA Framework: Spark Job Runtime Increases from 30 Mins to 3 Hours

## Question
A production Spark job that normally completes in 30 minutes suddenly takes 3 hours. No application code changed. What is your systematic troubleshooting checklist?


## 1. Systematic RCA Checklist

```
+-----------------------------------------------------------------------------------------------+
|                            Sudden Runtime Spike RCA Checklist                                 |
+-----------------------+-----------------------+-----------------------+-----------------------+
|  1. Input Data Volume |  2. Spark UI Metrics  |  3. Cloud Resources   |  4. Delta Metadata    |
| • Did input size 5x?  | • Check GC time (>15%)| • Spot preemption?    | • Millions of small   |
| • Data skew spike?    | • Disk shuffle spill? | • Cloud quota limits? |   uncompacted files?  |
+-----------------------+-----------------------+-----------------------+-----------------------+
```


## 2. Step-by-Step Diagnostic Steps
1. **Check Input Volume & Source File Distribution:** Verify if upstream sent 10x more files or uncompressed files.
2. **Check Executors Tab in Spark UI:** Identify if worker nodes died and restarted repeatedly due to Spot VM evictions.
3. **Check Task Event Timeline:** Inspect if stages spent 80% of runtime in Java Garbage Collection (indicating severe heap memory starvation).
4. **Target Table Small Files:** Verify if target Delta table accumulated hundreds of thousands of tiny unvacuumed files.
