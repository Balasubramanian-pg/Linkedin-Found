# Kill Me

## Problem / Question Statement

🤔 𝐂𝐃𝐂 vs 𝐂𝐃𝐅 𝐢𝐧 Databricks

We often hear about 𝐂𝐃𝐂 and 𝐂𝐃𝐅 in data engineering, and sometimes they sound like the same thing. But they solve two different problems.

𝐂𝐃𝐂 (𝐂𝐡𝐚𝐧𝐠𝐞 𝐃𝐚𝐭𝐚 𝐂𝐚𝐩𝐭𝐮𝐫𝐞) captures changes happening in the source system — inserts, updates, and deletes.

𝐂𝐃𝐅 (𝐂𝐡𝐚𝐧𝐠𝐞 𝐃𝐚𝐭𝐚 𝐅𝐞𝐞𝐝) captures row-level changes committed to a Delta table.

For example, 𝐂𝐃𝐂 helps bring changes from a source database into your Bronze layer. Once those changes are processed and written into a Delta table, 𝐂𝐃𝐅 helps downstream Silver or Gold tables consume only the changed records instead of processing everything again.

In Databricks, CDF also provides useful metadata such as:

- "_𝐜𝐡𝐚𝐧𝐠𝐞_𝐭𝐲𝐩𝐞"
- "_𝐜𝐨𝐦𝐦𝐢𝐭_𝐯𝐞𝐫𝐬𝐢𝐨𝐧"
- "_𝐜𝐨𝐦𝐦𝐢𝐭_𝐭𝐢𝐦𝐞𝐬𝐭𝐚𝐦𝐩"

One important distinction: 𝐂𝐃𝐅 𝐢𝐬 𝐧𝐨𝐭 𝐚 𝐫𝐞𝐩𝐥𝐚𝐜𝐞𝐦𝐞𝐧𝐭 𝐟𝐨𝐫 𝐬𝐨𝐮𝐫𝐜𝐞-𝐬𝐲𝐬𝐭𝐞𝐦 𝐂𝐃𝐂. They can work together in the same data pipeline.

Understanding where each one fits can make incremental data processing much more efficient.
